# 2000CO101 — Goldstone DSS-14 data inventory (Sep 2009)

Static dashboard listing, per day and per type, the Goldstone DSS-14 runs found on disk
versus those planned in the masterlog.

- `index.html` — the dashboard (self-contained, no internet needed).
- `build_co101_dashboard.py` — regenerates the page from the data tree (read-only scan).
  Usage: `python3 build_co101_dashboard.py [path/to/Goldstone/2009]`

Snapshot of the data download in progress; excluded days: sep26, sep28, sep29, sep30.
