Legend: how the types were identified

  • IMAGING / RANGING — raw maps.<YYYYMMDDHHMMSS>_1 delay-Doppler map runs. The masterlog setup (imaging or ranging, with its code length) is matched by start time UTC.
  • LPBK / SKY — calibration runs, identified by the -lpbk / -sky filename suffix.
  • CW — the masterlog's CW, 4 hops (10 s) rows. No raw CW run files are on disk for the included days.
  • CW — CW data: GSSR RDF records PSD*.rdf (OC) and VOLT*.rdf (SC). Headers give target, polarization and number of spectra (nspec). Per the JPL data notes, these are the only CW files.
  • Filenames mislead in general: the SHAPE set type inside a .obs file is the reliable test (doppler = CW, delay-doppler = DD).
